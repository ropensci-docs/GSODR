# Agroclimatology List

Internal function: Agroclimatology List

## Usage

``` r
.agroclimatology_list(file_list, isd_history, years)
```

## Arguments

- isd_history:

  isd_history file from NCEI

- years:

  Years being requested

- x:

  A `data.table` of GSOD data from .download_data

## Value

A list of GSOD stations suitable for agroclimatology work.
