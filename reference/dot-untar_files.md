# Untar GSOD Tar Archive Files

Internal function: Untar GSOD Tar Archive Files

## Usage

``` r
.untar_files(tar_files)
```

## Arguments

- tar_files:

  a list of tar files located in in
  [`tempdir()`](https://rdrr.io/r/base/tempfile.html)

## Value

Called for it's side-effects, untars the archive files in the
[`tempdir()`](https://rdrr.io/r/base/tempfile.html).
