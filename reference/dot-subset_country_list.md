# Subset country list

Internal function: Subset country list

## Usage

``` r
.subset_country_list(country, file_list, isd_history, years)
```

## Arguments

- country:

  Country of interest to subset on

- isd_history:

  isd_history.csv file from NCEI provided by GSODR

- years:

  Years being requested

- GSOD_list:

  List of GSOD files to be subset

## Value

A list of stations in the requested country.
